# R3-C8 角色级服务授权

日期：2026-10-21
任务：OM-R-C8
目标：端点授予支持角色维度；执行时按用户 ACTIVE 角色并集生效，并与用户授予兼容；变更入审计。

## 实现

- `V20__endpoint_role_grant.sql`：`endpoint_role_grant(endpoint_id, role_code, data_scope, expires_at, status)`，角色编码引用 `local_role(code)`。
- `ReleaseGatewayService`：
  - `GET /endpoints/{id}/role-grants`、`PUT /endpoints/{id}/role-grants/{roleCode}`（`grant.read/write`，OWNER+空间锁）；
  - 角色必须是已存在角色；状态 ACTIVE/REVOKED；`dataScope` 复用 `LabelScope` 校验；
  - 审计动作 `ENDPOINT_ROLE_GRANT`。
- 执行链 `CandidateService`：有效授予 = 用户授予 ∪ 用户 ACTIVE 角色授予；多条范围逐项 `LabelScope.intersect` 求交，任一范围不能扩大另一条。
- 前端 `EndpointGrantsPanel`：展示角色授予列表，可填写角色编码/状态/到期时间并保存；用户授予表单保持原样。

- 角色编码为文本输入，未做角色下拉（需要额外的角色目录读取权限组合）；后端会校验角色存在。
- 角色授予 UI 暂只提交不限额范围；带范围的角色授予可经 API 设置。
- 与空间角色、端点状态、策略范围的四层求交仍由既有执行链完成，本轮只新增端点角色层。
