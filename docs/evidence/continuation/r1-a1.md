新增用例覆盖：

1. `zeroOperationModelOnlyCandidatePublishesWithoutContractOrEndpoint`：0 操作 + 1 类 → MODEL_ONLY → 五门禁通过 → READY，`service_endpoint` 0 条，RELEASED 1 条。
2. `operationWithoutEnabledCaseStillCannotPublish`：1 操作无助手 + 0 用例 → TEST 失败 `NO_ENABLED_TEST_CASES`，prepare 409。
3. `modelOnlyOperationWithCasePublishesWithoutEndpointAndCannotBeCalled`：1 操作无助手 + 1 用例 → 发布成功、0 端点；内部调用返回 403 `ENDPOINT_FORBIDDEN`。
