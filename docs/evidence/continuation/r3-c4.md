# R3-C4 正式版本知识检索（增量）

日期：2026-10-21
任务：OM-R-C4
目标：正式版本复用冻结候选的 Lucene 知识索引检索，不读当前草稿；非成员拒绝。

## 实现

- `CandidateSupplyService.releaseSearch`：按 release 查 `space_id/candidate_id`，先空间角色鉴权，再加载候选冻结载荷并用其摘要查 Lucene。
- `GET /releases/{id}/knowledge-search?q=&limit=`（`knowledge.read`），返回 `releaseId/candidateSha256/hits`。
- `KnowledgeView` 增加"正式版本知识检索"：选择版本、输入中文词、显示命中术语/定义/相关度；版本列表来自 `/releases?spaceId=`。
- 候选级 `knowledge-search` 保持原样；两者共用 `FrozenKnowledge` 索引。

## 实体/事实关系（V21）

- `ont_knowledge` 增 `kind(TERM/ENTITY/RELATION)` 与 `subject_ref/predicate/object_ref`；旧行默认 TERM。
- 服务校验：TERM/ENTITY 定义必填；RELATION 必须有三元组；关系不关联概念。
- Lucene 文档把关系三元组并入检索文本，命中的 hit 带 `kind`；前端表单/列表支持类型与事实三元组。

## 限制

- **知识实体/事实关系**（kind=ENTITY/RELATION、主语-谓词-宾语）尚未建模，当前仍是术语/别名/定义/来源。
- 版本检索复用候选冻结载荷；未单独归档 Lucene 索引文件（P4 制品阶段再议）。
- UI 仅列出命中条目，未做高亮/分页。
