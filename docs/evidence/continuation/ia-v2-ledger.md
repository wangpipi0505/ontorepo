验收：`/data`、`/delivery`、`/trace` 可直接访问；`/spaces/:id/data|delivery|trace` 重定向并保留 `spaceId`。

### IA-03 本体空间管理表

## 3. 依赖与阻塞

| 项 | 条件 | 影响 |
|---|---|---|
| 全局聚合性能 | 目前按可见空间循环调用各服务 | 空间数量大时变慢；需改为一次 SQL 聚合 |
| 全局溯源上限 | 单类约 300 条 | 需要游标/分页设计 |
| 撤销范围 | 服务端无通用反向接口 | 删除类操作暂不可撤销，需草稿快照恢复 |

## 4. 更新规则

1. 每次 IA/视觉提交必须更新本表对应行的状态、提交号、剩余项。
2. 只有验收标准全部满足才能写“完成”；否则写“部分”并列出剩余。
3. 回复用户时必须引用本表 ID，不得用“已完成”掩盖“部分”。
4. 新增事项追加新 ID，不覆盖历史。
