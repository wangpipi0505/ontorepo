# R3-C6 操作与属性业务字段

日期：2026-10-21
任务：OM-R-C6
目标：操作补业务说明与执行条件；属性补显示名称；旧数据为空，不伪造业务语义。

## 实现

- `V19__operation_property_fields.sql`：
  - `ont_operation.description/precondition`（默认空串）；
  - `ont_property.display_name varchar(200)`（默认空串）。
- DTO：`Operation/OperationWrite` 增 `description/precondition`；`OntProperty/PropertyWrite` 增 `displayName`。
- 服务：`OperationService` 保存/更新；`ModelService.saveProperty` 保存/更新；长度分别 4000/200。
- 前端：操作弹窗增"业务说明/执行条件"；属性弹窗增"显示名称"；类型定义补可选字段。
- 冻结候选复制操作整行，助手契约沿用新增字段，无需额外转换。
