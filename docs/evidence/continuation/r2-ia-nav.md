- `layouts/WorkbenchLayout.vue`：22 个空间页签按 6 组折叠：概念建模 / 知识与数据 / 操作与测试 / 发布与服务 / 溯源审计 / 空间设置；空间概览独立。

- 无控制台错误；原有页面链接均可从组内进入。
