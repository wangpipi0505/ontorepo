## 语义

- 过滤在 SQL 内完成：对象=`subject_type+subject_id`，动作=`action`，时间=`created_at` 范围；仍先校验空间可见性。
- 旧审计行新列为 null，页面显示"未记录"，不回填猜测；执行记录分页按 `created_at DESC,id DESC` + `offset`，子记录仍按本批执行标识批量读取。
- 审计对象写入与业务同事务；发布提交的对象类型为 RELEASE，其 subjectId 即 releaseId。
- 审计动作在页面中中文化，原始 action 仍在详情 JSON 中保留。
