# C7 空间概览与图形映射补全

日期：2026-10-21。范围：开发计划 D-01 / D-02、详细设计 §5.1 / §5.2 的空间总览、查询与映射工作台。沿用既有批准设计与接口；未修改后端、接口契约、API 客户端类型、部署、相邻工程或 Git 状态。

## 交付内容

- 空间列表支持名称、编码、领域、状态组合查询；查询在完整授权列表本地执行，无结果有明确说明。每页六张卡片，每次最多两张卡片并发读取概览；本列表会话内按空间与草稿修订复用已读结果，刷新和重试显式重新读取。
- 空间卡片保留对象、属性、操作数，并补充关系数、规则数、当前正式版本、发布状态、模型冲突与映射完整性问题。归档、新建、编辑、进入空间仍保留。发布接口失败显示正式版本读取失败及重试，不回退成未发布、零问题或门禁通过。
- `/spaces/:spaceId` 已改为空间概览，增加概览导航。概览提供模型、关系、约束、规则、策略、操作、数据目录、版本动态及候选发布入口，展开模型冲突与映射问题的实体标识和详情。
- 图形映射从当前空间已登记数据源及真实元数据快照读取资源、字段、主键，展示源字段树与本体类层级、属性树。SVG 连线取实际 DOM 几何，支持滚动、75% / 100% / 125% 缩放、现有对象/属性/关系映射定位及关系连接键查看。
- 来源节点支持原生拖拽，同时保留按钮点选与 Tab / Enter 路径。资源只能连到本体类；字段需要明确所属的已保存对象映射，只能连到该对象目标类下类型兼容的属性。未知类型、需要转换和跨对象连接明确拒绝图形预填，并引导到原有完整表单。
- 新连线、名称匹配推荐均只预填原有映射表单，不发起写入。表单保留对象标识模板、复杂 JSON 过滤、转换、码表、关系连接键和变更影响；人工保存仍走原有 `expectedDraftRev`、错误处理与服务端校验。
- 推荐展示确定性规则分数、名称/类型依据、资源、快照标识和摘要，按分数排序，每项独立审查。分数明确不是模型概率；不自动接受或批量写库。
- VIEWER 可浏览与定位已有映射，不能预填、拖拽写入或保存。切源、切快照、切空间立即清空选择并隔离迟到读取；同空间重入时，事件入口再次核对工作区代次。

## 接口与数据真实性

概览复用以下只读接口：

1. `GET /spaces` 与 `GET /spaces/{id}`；
2. `GET /relations?spaceId`、`GET /rules?spaceId`；
3. `GET /spaces/{id}/conflicts`；
4. `GET /mappings/validate?spaceId`；
5. `GET /releases?spaceId`。

单空间汇总在读取前后核对 `Space.draftRev`；发生变化则拒绝混合汇总并允许重试。每项失败独立保留未知态，映射检查空集显示未检查，`valid=false` 显示未通过。正式版本按最大真实版本号选择，READY、DEPRECATED、CORRUPTED 分别说明消费状态。模型零冲突不代表发布五项门禁通过。

图形映射继续使用 `GET /datasources/{id}/snapshots?spaceId` 和快照详情接口，校验快照来自所选源列表且返回 ID 与选择一致。现有列表读取与写入接口没有改动。未引入图框架或新依赖。

## RED → GREEN 记录

1. 原空间页面运行新增三项测试，全部按预期失败：没有筛选控件、关系/规则/版本指标、发布读取失败与重试。
2. 图形映射组件实施前运行五项测试，全部按预期失败：不存在双树入口，故连线预填、错误类型、VIEWER、迟到隔离、推荐流程均不可达。
3. 增加实际 `MappingsView + MappingForm` 提交集成及映射校验指标两项测试，均先失败；接入后通过。完整表单测试验证对象和属性字段实际进入 POST 请求，并验证人工提交前没有写入。
4. 自查新增同空间重入未返回的反例，复现旧画布使用缓存权限继续预填；在连接/拖拽入口即时核验工作区代次后通过。
5. 父执行者提出预填设置时序的静态风险。原实现已有 `manual/prefill` 表单 key 重挂载，真实表单提交测试已通过，未复现漏填；最终改为在打开表单前一起设置 seed，消除多余挂载与元数据读取。此项不记为已复现缺陷。

## 独立验收边界

此报告记录组件与静态构建验证，不将 jsdom 几何测试写作真实浏览器验收。父执行者负责独立复审，以及真实服务下桌面/390px 的筛选、概览、拖拽预填、人工保存、滚动缩放及现有映射定位。共享 `onto-p1` 浏览器未由本任务操作。

发布接口在旧运行 JAR 返回 404 时，页面保留正式版本失败与重试；待父执行者的新 JAR 实测后再记录运行结果。不得将该环境故障解释为正式版本功能可删除。
