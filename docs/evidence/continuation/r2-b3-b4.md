# R2 B3/B4 体验增量：面包屑 + 发布状态中文

日期：2026-10-21

## B3 面包屑

- 新增 `breadcrumbs.ts`：空间路径 + `tab` query → "区 / 页" 层级；执行追溯为"操作与测试 / 执行记录 / 执行追溯"。
- 新增 `Breadcrumbs.vue`，挂在顶栏与主内容之间；上级"执行记录"可点，当前页只读。
- 容器页签切换时面包屑随 query 更新（如 概念建模 / 关系、发布与服务 / 发布向导）。

## B3 全局搜索

- 顶栏新增 `GlobalSearch`：首次聚焦按空间读取对象/操作/规则/数据源四类目录，本地子串过滤（最多 8 条），不新增后端接口。
- 结果按类型标注，点击跳转：对象→`model?classId=`、操作→`operations?entityId=`、规则→`model?tab=rules`、数据源→`datasources`；Enter 打开首条，Esc 关闭。
- 某一类读取失败不阻断其他类别（`Promise.allSettled`），不做假数据回退。

## B4 高频枚举中文化

- `publication.ts` 新增：
  - `publicationStatusLabels`：FREEZING/VALIDATING/TESTING/REVIEWING/READY_TO_COMMIT/COMMITTED/CANCELLED/FAILED → 冻结中/机器检查中/验收测试中/待人工复核/待提交发布/已提交发布/已取消/检查未通过；
  - `checkConclusionLabels`：PASSED/FAILED/NOT_CHECKED → 通过/未通过/未校验。
- 发布向导候选状态、五项门禁结论改用中文；`PublicationPanel` 状态 tag 同步。
- 相关前端断言从英文枚举改为中文（断言仍校验状态迁移，不放宽）。
