## 实现范围

- 码表独立页面：UNIT / VALUE、条目编辑、创建 / 更新 / 删除；客户端拒绝空编码和重复编码。
- 属性独立分面字段组件：单位码表及单位、取值码表、真实 JSON 标量默认值、枚举、上下界和主键；客户端验证类型、范围、枚举默认值和必填主键。编辑与删除前读取真实引用影响，引用受限时提示服务端阻断。
- 关系与约束独立页面：关系端点、四类基数、逆关系名称、传递 / 对称；请求不包含可伪造的 inverseOf。约束覆盖范围、关系基数、对象互斥与属性依赖，并固定匹配目标类型。
- 规则与评分、执行策略独立页面：条件、校验动作、严重性；评分指标 / 分段 JSON、缺值处理、稳定排序、禁算字段、解释；策略资源上限、FAIL、读取范围与操作绑定。复杂评分结构保留 JSON 数值类型，完整语义校验仍由后端承担。
- 四类操作：OBJECT_QUERY / RELATION_QUERY / RULE_CHECK / SCORING；策略和规则绑定；规则类不要求 SELECT。关系查询明确展示 P1 包内模型查询限制。
- TTL / OWL 导入导出：粘贴 / 本地文件、预览差异、语法 / 冲突 / 不支持构造逐项展示、显式勾选人工确认后应用。修改原文即撤销确认；失败预览不可应用；导出读取真实 TTL 并提供下载。
- 草稿四类冲突面板；候选冲突 / 一致性 / 用例检查、冻结用例执行与结果留痕；返回摘要必须匹配选定候选。初期 eligible 不显示为正式发布资格。
- OWNER 超范围豁免：仅真实 CONSISTENCY / NOT_CHECKED / SUBSET_EXCEEDED 且候选修订仍匹配当前草稿时出现；要求原因，记录审批信息并重新检查。未提供 INCONSISTENT / TIMEOUT / ENGINE_ERROR 豁免入口。
- 用例独立页面：问题、命中操作、输入、预期结果、启用状态；默认 EXACT，逐用例显式选择 CONTAINS。
- 保留深蓝导航 / 白卡 / 浅灰画布和窄屏布局。每个领域有独立组件；共享逻辑仅管理列表提交、修订锁及引用读取。所有写表单保持唯一真实 el-form，无嵌套 form。只读用户可展开完整结构化定义，不提供写入口。

## 并发及接口边界

新增列表使用 readDraftSnapshot 前后夹读，只有完整列表和空间修订一致时才恢复工作区写权限；表单采用 useDraftRevision 固定打开时修订。409 后保留输入并锁定旧表单，工作区后来刷新也不能复用旧表单再次写入。

额外修复了原属性面板的列表修订关联：属性列表也采用一致性夹读；编辑 / 删除携带该列表的读取修订。类树刷新使工作区变为新修订时，旧属性不能借用新修订覆盖并发修改。局部属性读取不恢复整个工作区写权限。

全空间属性选择器按主执行者确认采用 `GET /spaces/{id}/properties`，原 `GET /properties?spaceId&classId` 必填约定保持不变。P1 扩展类型暂按 `contracts/p1-extension.md` 显式维护在 API 类型包，旧 generated.ts 未伪装为已更新的后端产物。

候选操作仅调用 `/candidates/{id}/operations`；操作读取失败和旧候选缺少操作均不回退草稿。候选试执行携带结构化 input；候选检查和测试不发送草稿用例或草稿规则。生产代码没有补结果的演示数据，也没有浏览器业务持久化。
