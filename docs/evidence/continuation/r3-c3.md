# R3-C3 映射静态类型兼容

日期：2026-10-21
任务：OM-R-C3
目标：属性映射保存时即比对源字段类型与本体属性 `range_type`，不兼容立即失败，不等到运行期。

## 实现

- `MappingService.validate`（properties 分支）：读取对象映射所属快照资源字段元数据，按字段名取源类型；与属性 `rangeType` 比对。
- 兼容矩阵：
  - 默认/IDENTITY：STRING=STRING、INTEGER=INTEGER、INTEGER→DECIMAL、DECIMAL=DECIMAL、BOOLEAN、DATE 同类；
  - `TO_STRING`：目标必须 STRING；
  - `TO_NUMBER`：目标 INTEGER/DECIMAL，源 STRING/INTEGER/DECIMAL；
  - `TO_BOOLEAN`：目标 BOOLEAN，源 STRING/BOOLEAN；
  - `CODEBOOK`：两端 STRING。
- 快照字段缺类型或未知类型时不做静态阻断，保留运行期校验，避免伪造兼容结论。
- 不兼容返回 `409 MAPPING_TYPE_INCOMPATIBLE`，消息含源字段与目标类型。

## 验证

```powershell
mvn ... "-Dtest=P3MappingTest" test
# 全部通过；新增 propertyMappingRejectsIncompatibleSourceTypeAtSave：
#   priority(integer) → 任务编号(STRING) 保存即 409 MAPPING_TYPE_INCOMPATIBLE
```

- 既有 P3 映射/查询/关系用例通过，说明 INTEGER→INTEGER、STRING→STRING、BOOLEAN→BOOLEAN 不会被误伤。
- Flyway 17 迁移已应用（本轮无新迁移）。

## 限制

- 前端沿用统一错误提示，未做字段级行内高亮；映射表单会显示服务端消息。
- 仅覆盖属性映射；对象键/关系 JOIN 的字段存在性仍由既有 `fields()` 校验，类型兼容不扩张到表达式。
