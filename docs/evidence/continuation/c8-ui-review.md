## 已核验部分

- IAM 请求字段、状态枚举、修订与分页响应和实际 `IamDtos` 对齐；密码仅存在写入输入，用户更新不夹带密码字段。
- 会话权限初始为 null，读取失败清空；旧主体迟到权限成功不授予新主体，旧主体迟到失败也不清除新主体已取得的权限。系统管理能力没有被写入候选或浏览器持久存储。
- 用户/角色表单绑定打开时的 `expectedRevision`；IAM 冲突保留输入并暂停重复提交。没有角色目录读取权限时，更新用户仍保留已知角色 ID，不因目录不可见自动撤销已有角色。
- 路由、菜单和主要业务写入策略与实际权限目录一致；试执行、测试、服务消费、创建空间使用独立权限；OWNER 发布豁免未被系统管理员或普通编辑者功能权限替代。
- 规则试执行只读取候选操作并筛选该候选实际绑定的规则，提交不含任意 `ruleIds`。冻结操作读取失败后没有草稿回退，也没有残留可提交表单。
- 批量测试组件校验 SHA，空用例不标记通过，父组件收到完成通知前先解除提交锁；后端要求的阶段限制已反映到发布入口。
- 组件按路由页面、编辑表单、权限选择、冻结试执行/测试组件和组合逻辑拆分；中文注释主要解释不可变内容、权限、修订和竞态边界。窄屏有对话框最大宽度、分组权限纵向排列、审计快照单列和表格内部横滚；这些静态规则不代替真实 390px 验收。
