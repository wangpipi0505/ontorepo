# R3-C7 规则引用与同分策略（增量）

日期：2026-10-21
任务：OM-R-C7
目标：规则详情可见被哪些操作引用；评分同分策略可配并随冻结候选生效。

## 实现

- `RuleService.references` + `GET /rules/{id}/references`（`rule.read`）：返回引用该规则的操作 `id/code/name/kind`；先按规则所属空间鉴权。
- `RulesView` 操作列新增"引用操作"对话框，展示只读列表；无引用明确显示。
- `ScoringPolicy` 同分策略从固定 `STABLE_ID` 扩展为 `STABLE_ID | INPUT_ORDER`：
  - `STABLE_ID`：同分按 ruleId 升序（原行为）；
  - `INPUT_ORDER`：同分保持操作 ruleIds 的输入顺序；
  - 非法值仍拒绝保存。
- `FrozenExecutor` 评分排序按冻结评分配置选择比较器；冻结候选不读新草稿。
