# R2 IA-S2 建模工作台侧栏（增量）

日期：2026-10-21
任务：OM-R-B2（S2 建模容器）
目标：建模页从"树 + 属性面板"升级为画布主视图 + 对象上下文侧栏，减少关系/约束/规则来回跳页。

## 实现

- `ModelView` 右侧面板改为 `el-tabs`：
  - **属性**：既有 `PropertyPanel`（新增/编辑/删除属性）；
  - **关系 N**：当前对象作为起点或终点的关系，显示名称/方向/基数，附"去关系页维护"；
  - **约束 N**：`targetType=CLASS && targetRef=当前对象` 的约束；
  - **规则 N**：`applicableClassId=当前对象` 的规则（名称/类型/级别）。
- 加载：`/constraints?spaceId=` 与 `/rules?spaceId=` 与关系/冲突同批读取；失败不阻断画布。
- 画布选中节点后侧栏即时切换上下文；空列表明确显示"暂无"。

## 浏览器验证

- 选中"任务"节点：侧栏出现 `属性 / 关系 1 / 约束 0 / 规则 0`。
- 切到"关系"页签：显示"自动化画布关系 · 任务 → 草稿新增对象 · ONE_TO_MANY"及维护入口。
- 画布、工具栏、拖拽/连线模式不受影响。
