# R3-C1 空间与数据源治理字段

日期：2026-10-21
任务：OM-R-C1
目标：空间补说明与最近修改；数据源补说明、维护主体、租户；旧数据可读、不伪造维护主体。

## 实现

| 层 | 改动 |
|---|---|
| DB | `V17__governance_fields.sql`：`ontology_space.description/updated_at`（旧行回填 `created_at`）；`datasource.description/owner_id/tenant` |
| 后端 | `SpaceService` 创建/更新说明，所有草稿写入推进 `updated_at`；`Space`/`SpaceCreate`/`SpaceUpdate` DTO 增字段；`DatasourceService` 保存说明/租户/维护主体并做用户存在性校验；`SAFE` 列表列补三字段 |
| 前端 | 空间弹窗增"空间说明"，卡片显示说明与最近修改；数据源表单增说明与租户，列表增说明/租户列；新建数据源默认维护主体为当前用户 |

## 语义与限制

- 旧空间 `updated_at` 取创建时间；旧数据源 `owner_id` 为 null，页面不显示默认维护人，避免伪造。
- 说明与租户长度分别受 4000/200 限制；维护主体必须是存在的本地用户，否则 400。
- 新建数据源默认维护主体为当前用户；尚不支持在表单中选择其他空间成员（后端已接受 `ownerId`），列入 COM 后续。
