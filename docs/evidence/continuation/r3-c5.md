# R3-C5 数据目录字段级下钻

日期：2026-10-21
任务：OM-R-C5
目标：数据目录从数据源下钻到快照资源、字段与本体属性绑定；提供空间路径别名。

## 实现

- `MappingService.catalog`：每个数据源附 `resources[]`（来自最新快照）：
  - 资源：`name`；
  - 字段：`name/type/bindings[]`；
  - 绑定：`objectMappingId/classId/className/propertyId/propertyName`；未绑定字段为空数组，不伪造。
- 新增 `GET /onto/spaces/{id}/catalog` 别名，与 `/data-catalog?spaceId=` 同视图、同 `mapping.read` 权限。
- `DataCatalogView.vue`：数据源表支持展开，展示资源 → 字段（源类型）→ 本体绑定标签；无快照时提示先同步。
- `DataCatalog` TS 类型补 `resources`。

## 验证

```powershell
mvn ... "-Dtest=P3MappingTest#catalogDrillsDownToFieldsAndPropertyBindings" test
# 通过：p3_source.tasks.task_id(text) → 任务编号；绑定含对象映射 id；空间路径别名同视图
pnpm typecheck   # exit 0
pnpm test        # 31 files / 259 tests passed
pnpm build       # exit 0
```

## 限制

- 仅读最新快照；历史快照下钻未做。
- 字段行尚无"从字段新建映射"的动作/预填入口，只有绑定展示；列入 C5 收口缺口。
