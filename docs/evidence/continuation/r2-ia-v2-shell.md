# 前端 IA v2：模块同级化（第一阶段）

日期：2026-10-21
背景：用户指出“所有功能被塞进空间工作台”，本体空间与概念建模、知识与数据、测试与发布、溯源审计应为同级模块；页面还存在居中留白、布局粗糙问题。

## 本轮已改

- 左侧导航改为 **5 个一级模块 + 系统**：
  - 本体建模：本体空间（列表）/ 空间概览 / 建模工作台
  - 知识与数据
  - 测试与服务封装
  - 数据溯源审计
  - 空间设置（OWNER）
  - 系统：当前账号 / 用户 / 角色 / 系统审计
- 去掉空间内 8 组折叠导航，不再把知识、发布、审计埋在“空间”侧栏。
- 新增模块容器路由：
  - `/spaces/:id/data`：知识物料 / 数据源 / 字段映射 / 数据目录 / 从数据抽取 / TTL·OWL
  - `/spaces/:id/delivery`：验证与候选 / 发布与服务
  - `/spaces/:id/trace`：执行与追溯 / 审计记录
- 面包屑补充模块页。
- 主内容区去掉 `max-width:1600 + margin:auto`，改为全宽 `100%` + 24/28px 内边距。
- 保留旧路由可达（尚未批量 redirect）。

## 浏览器验证

- `/spaces` 列表进入空间后：导航出现“本体空间 / 空间概览 / 建模工作台 / 知识与数据 / 测试与服务封装 / 数据溯源审计 / 空间设置”。
- `/spaces/:id/data` 六个页签正常；`delivery` 两页签；`trace` 两页签。
- 1920 宽下主内容填满，无 1600px 居中限宽。

## 已知未完成（后续阶段）

1. **本体空间列表页**仍是原卡片/列表，需改为管理表：名称/编码/领域/状态/对象数/版本/更新时间，行内“进入建模 / 数据配置 / 发起测试 / 更多”。
2. **建模工作台**仍是“画布 + 右侧属性页签”，需改为**画布占主区**：全高画布、对象/关系/规则/冲突/策略/操作作为画布下方或右侧表格区；补齐撤销/草稿恢复。
3. **知识与数据**：当前是 6 个旧页面容器拼接，仍有重复页头；需改为“物料库列表 + 详情/引用”布局，支持分类、搜索、建模时引用。
4. **测试与服务封装 / 溯源审计**：容器内仍嵌套旧页头与旧页签，需合并为单一模块页；审计增加按本体名称/类型检索与可视化。
5. 全局视觉：统一页头、工具栏、表格密度、表单抽屉；去掉重复标题与大面积留白。
