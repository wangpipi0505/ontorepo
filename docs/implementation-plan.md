# 领域本体工具 P1 首批实现计划

> 执行依据：用户已批准详设并授权编码；使用 subagent-driven-development 分任务实施与复核。无需再次请求设计批准。

**目标：** 独立运行“登录 → 空间 → 对象/属性 → 操作 → 候选冻结 → 试执行 → 执行留痕”。

**架构：** Maven 模块化单体，按详设建立 common/space/model/operation/trace/designer-api，PostgreSQL 持久化；Vue 门户与 API 类型契约独立，开发服务器代理后端。首批不宣称完整 P1 出口通过。

**技术栈：** Java 21、Spring Boot 3.5.5、Jena 5.6.0、PostgreSQL；Vue 3.5、TypeScript、Pinia、Element Plus、Vite、pnpm。

## 全局约束

- 中文注释解释核心规则、事务、权限、异常及组件职责；前端按职责组件化。
- 身份来自真实本地令牌，空间权限默认拒绝，禁止用身份请求头绕过登录；数据库是权威。
- 冻结内容不可变，执行不读取草稿；用户输入不能使模型查询访问网络或文件。
- 每次草稿写入校验修订，禁止并发静默覆盖；审计与写入同事务。
- 页面采用深蓝导航 `#142842`、蓝色主操作 `#2563eb`、浅灰背景 `#f5f7fa`、白色工作面、灰蓝辅助文字 `#64748b`；中文字体 Microsoft YaHei / PingFang SC，代码字体 Consolas。对象树和属性面板为建模主工作区，操作和试执行分别成页。
- 不提供虚构统计、假数据兜底、没有实现的菜单动作。后端失败要能重试；归档和删除要确认；窄屏布局和键盘操作可用。

## 任务与文件边界

- [x] OM-P1-01：独立工程、执行契约与本体台账。主执行者负责根配置、`contracts/p1-api.md`、`docs/`、`deploy/` 和设计目录台账。先核对既有目录与待决项；保存原文基线摘要；建立启动/停止说明。
- [x] OM-P1-02 / OM-P1-03：后端闭环（分别对应空间建模与操作/候选/留痕）。后端实现者负责 `pom.xml`、`onto-*/`；分层拆为身份/空间授权、空间写事务、模型校验、操作校验、候选归档、执行和审计。对外接口严格依 `contracts/p1-api.md`。
  - 先写真实 PG 集成失败用例：匿名访问、无授权读写、VIEWER 执行、层级环/跨空间父级、同级重名、过期修订；先运行记录失败，再实现。
  - 建 Flyway 迁移（本地用户/令牌、空间授权、模型、操作、候选、执行/步骤/审计），避免模拟数据库语义。
  - 验证冻结后改稿不改变旧候选结果、相同内容摘要稳定、载荷损坏拒绝、查询 SERVICE/FROM/扩展函数拒绝和分页上限；执行留痕含候选摘要。
  - Maven：`mvn -B verify`；测试使用独立真实 PG，缺测试配置必须明确失败，不能静默跳过。
- [x] OM-P1-04：前端闭环。前端实现者负责 `web/`；`apps/onto-admin/src` 按 layouts/views/components/composables/stores 分层；`packages/api-client` 维护类型化客户端；`packages/shared-ui` 维护通用状态组件与 tokens。
  - 页面：登录、空间列表/新建、对象树与属性编辑、操作列表/编辑、候选与试执行、执行记录。
  - API 错误统一转换；登录过期回登录；操作防重复提交；切空间/切对象时清除旧选中与旧异步结果；修订冲突刷新并保留可理解反馈。
  - 在 API 请求与对象树关键逻辑上先写失败测试，再实现；运行 `pnpm test`、`pnpm typecheck`、`pnpm build`。
- [x] OM-P1-05：联调与审查。主执行者启动独立服务、跑真实 API 和浏览器链路，截取桌面/窄屏页面，检查交互与中文注释；独立审查代码后修复重要问题，记录命令、结果、限制和待决事项。
